# Experiment index

Historical experiment archives are retained in Git as durable research records.
Large generated artifacts under each experiment’s `artifacts/` directory remain
ignored. Measurements and source hashes describe the experiment that produced
them; they are not current claims.

The current source, verification limits, compact regression policy and durable
research-store pointers are recorded in [the handoff](../docs/HANDOFF.md).
Resolve the research root through private runtime configuration. Frozen historical
experiments remain evidence for their own source and device, not current claims.
