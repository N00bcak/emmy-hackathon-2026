`python -m tools.research_cases ... --family atomic_matmul --seed 4242 --shape
7 5 9`. It exercises a non-square split-K reduction with `zero_outputs` and an
atomic f32 store. The expected values come from the independent float64 NumPy
matmul reference in `tools/research_cases.py`, not from the compiler.
